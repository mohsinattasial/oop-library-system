# OOP Library Management System

An educational Python CLI for books, members, borrowing, returns and late fees.

## Run
```bash
cd oop-library-system
python cli.py
```

## Tests
```bash
cd oop-library-system
python -m unittest discover -s tests -v
```

## Structure
- `oop-library-system/cli.py`: CLI
- `oop-library-system/src/`: domain logic
- `oop-library-system/tests/`: automated tests

Uses Python standard library only. Start inside the nested `oop-library-system` directory. Author: Mohsin Atta.
